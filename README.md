# Hi, I'm Prakash 👋

**Karli Surya Venkata Prakash Rao** · Java developer · builder of open-source tools

I trained as a mechanical engineer at Aditya College of Engineering and Technology, spent most of college building robots, and never stopped chasing new technology. Today I work as a Java developer in banking (anti-money-laundering, watchlist screening), and I'm an Oracle Certified Java 8 Associate.

Outside work, I build open-source projects for the public, especially ones that help **women get back to work** and build real careers. The idea: anyone can send an idea by phone call, voice note or WhatsApp. No money is asked for or paid. Contribution points depend on the idea itself, never on when it arrived, and if the idea already exists in the market, the work goes into enhancing it.
